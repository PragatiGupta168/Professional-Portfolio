# Pragati Gupta – Professional Portfolio

Welcome to my **personal portfolio website**, showcasing my projects, skills, and contact information.

## Live Demo
Check out my portfolio live here: [Pragati Portfolio](https://pragati-portfolio168.netlify.app)

## Description
This is a **modern, responsive personal portfolio website** built with **React.js and Vite**, designed to present my skills, projects, and professional presence online.  
It features an interactive UI, smooth animations, and a contact form integrated with **EmailJS** for direct messages.

## Features
- Interactive UI with smooth animations using **Framer Motion**
- Fully responsive design for desktop, tablet, and mobile
- Contact form with **EmailJS integration** for direct messaging
- Quick links to **GitHub, LinkedIn, Email, WhatsApp, Instagram, and Facebook**
- Light & dark mode ready

## Tech Stack
- **Frontend:** React.js, Vite, CSS
- **Animations:** Framer Motion
- **Form Handling:** EmailJS
- **Hosting:** Netlify
